It is a project that demonstrates student information management and documentation.

## 2. What is GitHub Pages?

GitHub Pages is a service used to host static websites directly from a GitHub repository.

## 3. What is Markdown?

Markdown is a lightweight formatting language used to create documentation.

## 4. Is GitHub Pages free?

Yes, GitHub Pages is available for public repositories on GitHub Free.

## 5. How can I access the documentation?
