
# Usage Instructions

This page explains how to access and use the Student Management System documentation.

## Getting Started

1. Open the GitHub repository.
2. Visit the documentation website.
3. Read the Home page.
4. Follow the instructions provided.

## Installation

Clone the repository using Git:

```bash
git clone https://github.com/daliarjain-dev/VCS.git
cd VCS
```

## Basic Git Commands

Check repository status:

```bash
git status
```

Download the latest changes:

```bash
git pull
```
